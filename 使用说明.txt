Fast BLF Converter —— 使用说明（绿色免安装版 v0.2.1）
================================================

【怎么用】
1. 解压 zip 到任意目录（例如 D:\Tools\FastBLFConverter）。
   * 不要放在 C:\Program Files 等需要管理员权限的目录，也不用安装、不用管理员运行。
2. 双击 FastBLFConverter.exe。
3. 点「📂 批量添加 BLF」或直接把多个 .blf 文件从资源管理器拖进左侧列表。
4. 给通道绑 DBC（像 CANalyzer 那样，在通道节点上右键）：
   * 在右侧树的「通道 Ch1 / Ch2 …」节点上右键 → 「📄 添加 DBC…」，选该通道对应的 .dbc。
   * DBC 会作为该通道的子节点显示，后面跟解析状态（✓ 已解析 / ✗ 解析失败）。
   * 解析失败**不会弹窗**：通道旁红字提示，鼠标悬停看完整原因；该通道信号解不出来，
     但**不会影响其它通道**的导出（失败的通道会被跳过并记在结果说明里）。
   * 绑错了不需要单独删：点工具栏「🗑 全部清除 DBC」重新绑（本工具不提供删单个通道 DBC 的入口）。
   * 通道节点**只增不减**：启动时有 Ch1~Ch8；点「🔍 解析信号」后不会因为你只绑了 1、2 号就把
     其他通道收走。通道不够用就点工具栏「➕ 添加通道…」（或在右侧树空白处右键），输入 1~64 任意通道号；
     没在本批 BLF 里出现过的通道会标注「（无帧观测，右键可添加 DBC）」。
5. 所有 DBC 绑完后，点工具栏「🔍 解析信号」，右侧出现「通道 → DBC → 报文(带 ID 与周期) → 信号(带单位)」树。
   * 还没添加 BLF 也能点：这时只按 DBC 列出报文（帧数显示 0）。
   * 解析进度按**文件**推进（每转完一个切片前进一格，右侧显示本文件已扫帧数），
     不会出现"到 100% 又退回去"那种来回跳。
   * 重新解析会**保留你之前的勾选**（按通道/报文/信号名匹配）。
6. 在右侧勾选要导出的报文/信号（顶部搜索框可模糊过滤；「全选当前过滤项」/「一键清空」）。
7. 底部选择策略：
   * [✓] 按报文周期拆分为独立时序子表（推荐）：每张表只有自己那个周期，不会出现空白行。
   * 取消勾选 → 合并成一张宽表；建议再选一个重采样频率（1 / 10 / 50 / 100 Hz），
     否则各报文周期不同会产生空值。
   * 时间列格式：相对时间（秒，默认）/ 相对时间（毫秒）/ 绝对时间（日期 时间）/ Unix 时间戳（秒）。
     * 「绝对时间」= BLF 文件头里记录的录制时刻**原样输出**（与 CANalyzer 显示的那套时间对得上）。
     * 「相对时间」以本次全部输入文件中最早的时间戳为 0；多片切片一起转时仍保持时间递增。
   * 填充方式（宽表模式可用；拆表模式不需要，同一张表里周期一致不会有空值）：
     * 阶梯保持（推荐，默认）：把最近一次**真实采样**保持到下一拍。它**不会造出没测过的数**，
       状态位 / 档位 / 计数器 / 报警标志这类信号必须用它 —— 线性插值会把档位 1→2 插成 1.5。
     * 线性插值：在两个真实采样点之间连直线。**会造出从未采样过的中间值**，
       只适合确认是连续变化的物理量（电压 / 温度 / 电流）；选它时结果说明里会给出提示。
     * 不填充：保留空值。空值本身就是信息 —— 「这一拍这个信号没有采样」。
   * 最大保持时长（仅"阶梯保持"可用，0 = 不限）：超过这么久没收到新采样就不再保持、留空。
     用途：传感器掉线 30 秒时，不加限制会显示成"温度一直是 25°C"（把"没数据"伪装成"数据没变"）；
     填上它（例如 500ms）就会老老实实留空，被置空的行数会在结果说明里按信号报给你。
     经验值：填该信号周期的 3~5 倍（100ms 周期 → 300~500ms）。
   * 导出格式：CSV（通用表格，Excel/WPS/JMP 直接双击打开）/ Parquet（最快、供脚本分析）/
     Excel（.xlsx，拆表模式下每个报文一个 Sheet）。
8. 点「🚀 启动多核极速转换」，选输出目录。
   底部进度条实时显示：阶段 / 已完成文件数 / 当前文件 / 已解码帧数 / 速率 / 耗时。
9. 完成后在同一位置显示绿色结果（子表数量、耗时、输出目录）；
   若数据量超过 Excel 行数上限会自动降级为 CSV 并说明原因（不会静默截断丢数据）。

【配置预设：换项目不用重新勾】
* 「💾 保存配置」：把当前项目的「DBC 搭配 + 选中信号 + 导出策略」存成一个名字（例如「BMS项目A」）。
* 「📂 加载配置」：下次直接选名字 → 自动绑 DBC、自动解析信号、恢复勾选与导出策略。
* 「🗑 删除配置」：删掉不再需要的预设。
* 配置是普通 JSON 文件，默认放在程序目录的 configs\ 下（该目录不可写时自动改用用户目录，
  状态栏悬停可看到实际路径）；可以直接拷给同事或带到另一台电脑用。
* 如果配置里的某个 DBC 在别的电脑上不存在（路径变了），只在对应通道旁红字提示，其余照常工作。

【输出文件命名】
* 拆表模式：Merged_Ch1_VehSpd.csv / .parquet；Excel 模式统一为一个 Merged_Report.xlsx，每个报文一个 Sheet。
* 宽表模式：Merged_All_Signals.csv / .parquet / .xlsx。
* 宽表模式下，若不同报文里有同名信号（真实 DBC 里 Counter / CRC / Alive 很常见），
  会自动加报文名前缀（MsgA_Counter）避免列名冲突，并在结果说明里列出改名清单。
* 时间列永远是输出表的第一列，名字固定叫 timestamp。

【常见问题】
* 提示「Rust 内核未就绪」：程序目录不完整（fast_blf_core 的 .pyd 缺失），请重新解压完整压缩包。
* 报「BLF_PARSE」：该文件可能使用了不支持的压缩容器（LZMA）或文件损坏；错误信息里带文件名。
  遇到请把该文件反馈给工具维护者，并先用未压缩/较小切片重试。
* 某个通道信号解不出来：看通道旁的红字与悬停提示 —— 通常是该通道的 DBC 解析失败。
  **本版已能自动处理**中文项目里最常见的两类 DBC：ANSI/GBK 编码（中文 Windows 上 CANdb++ 的默认保存格式）
  与 UTF-8 BOM，以及 `CM_ BA_` / `BA_DEF_REL_` 这类与该工具无关的属性语句；
  被自动处理过时，DBC 节点会显示「✓ 已解析（已规范化）」，鼠标悬停可看具体做了什么。
  若仍失败：先用「全部清除 DBC」重绑，仍不行请把那个 .dbc 反馈给工具维护者（错误提示里带行列位置）。
* 宽表里一堆空值怎么办？三个办法，按推荐顺序：
  ① 改回「按报文周期拆分子表」（默认）—— 结构上就不会有空值；
  ② 选一个重采样频率（网格对齐）+ 阶梯保持；
  ③ 保持原时序 + 阶梯保持（空值会被前值填满，但要清楚这是"保持"而不是"新测到的"）。
* 填了"向前保持"以后还算不算真实数据？**它不会造假值**（每个数都来自真实采样），
  但会把"未采样"变成"采样了且没变"。所以：查值和画图放心用；
  算变化率/微分时会得到一堆 0；跨通信中断时**务必**设「最大保持时长」，否则丢帧会被旧值掩盖。
* 杀毒软件弹窗：本工具为未签名程序，可能被企业 EDR 拦一次。请让 IT 加白名单
  （本程序不做任何注册表/系统目录写入，也不会自我释放临时文件）。
* 大数据量（上百万行）：优先选 Parquet；Excel 建议只导出需要的报文。

【性能提示】
* 多核并行：文件越多越能打满 CPU。
* 内存峰值可控（默认按 1.5GB 预算分片落盘），不需要手动分批。
* 想更快：只勾选真正需要的报文/信号（未勾选的报文在字节层直接跳过，不参与解码）。
