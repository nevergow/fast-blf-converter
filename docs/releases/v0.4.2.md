# v0.4.2 —— 应用图标 + README 改版

这一版**没有功能改动**。补上了程序图标（此前在任务栏 / Dock 里是系统默认图标），
把 README 重写成「先讲人话」的版本，并给 Windows 包加了图标资源。

## 一、应用图标

* 图标源是 `gui/assets/icon.png`（512×512），`scripts/make_icons.py` 一次生成全部产物：
  * **Windows exe 资源图标** `packaging/icon.ico`：16/24/32/48/64/128/256 共 7 档
    （已在 CI 产物里核验：exe 内 `RT_ICON` 7 个 + `RT_GROUP_ICON` 1 个，256 档在位）
  * **macOS 图标** `packaging/icon.icns`：10 档，将来做 `.app` 时用
  * **运行期图标**：启动时由 `gui/main.py` 的 `apply_app_icon()` 加载，
    窗口 / 任务栏 / macOS Dock 都取这一份
* 18–32px 这类小尺寸用「以红色 FBC 块为中心的紧凑裁切」，48px 起恢复完整构图 ——
  完整构图缩到 16–32px 只剩一团噪点，小尺寸下认不出来。
* 打包差异：Windows 走 `EXE(icon=...)`；macOS onedir 产物不是 `.app`，Dock 图标在运行时设置。
  CI 新增一条断言：`_internal/gui/assets/icon.png` 必须进包。

## 二、README 改版

旧版第一屏就是四个版本的变更日志（吞吐数字、内存公式、panic 根因），不了解项目的人
看不到「这是什么、给谁用、怎么跑起来」。现在改成：

> 一句话定义 → 术语白话解释（BLF / DBC / Parquet）→ 「它解决什么」痛点对照表 →
> 三步用起来 → 能做什么 → 下载 → 常见问题 → 已知限制

之后才是架构、验证数据、本地开发、打包等技术章节；**四个历史版本的说明原文一字未改，只是折叠**。
顶部换成 Notion 封面式的全幅横幅（浅色 / 深色主题各一版，按主题自动切换）。

## 三、兼容性

* 命令行参数、`scan()` / `convert()` 契约、配置预设、DBC 绑定方式**均无变化**；
* 对外可见的差异只有程序图标与文档；
* 老的 `configs/*.json`（`schema=1/2`）照常可直接加载。

## 四、验证

* 本机：`--selftest` 通过；日志确认运行期图标加载；Dock 图标实测生效
  （`NSApplication.applicationIconImage` 位图与源图逐像素比对，MAD 4.2 / 设置前 145.9）；
* CI（Windows 真机）：冻结态 `--selftest` → `SELFTEST_OK version=0.4.2 kernel=yes`，
  日志确认 `_internal/gui/assets/icon.png` 已加载，exe 按时退出；
* 已知：CI 里的「冻结态配置自检」在窗口版 exe 上仍会超时（历史问题，不阻塞发布，
  详见 README「已知限制」第 4 条），配置功能在开发态与本机打包态均验证通过。
