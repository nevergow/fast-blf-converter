## 用户原话（这是验收标准）
> 「如果信号多一些，就会卡死…一开始展现的是整个时间段的数据…只有放大了才流畅」
> 「切换时间格式时会需要重新解码，不能缓存吗？这种改变应该是无感的」
> 「增加可分离的坐标、多行展示，像 canalyzer；可改曲线颜色；可改展现方式（曲线/散点）」
> 「关于全选那个部分，你设计的太奇怪了，只需要一个复选框就能搞定，反选是没必要的」
> 「车道多行是可选项吧？我也可以切换为多 Y 轴，或一个 Y 轴」
> 「用的时候体验最重要，卡顿、延迟、卡死、重新加载要尽量优化」

## 要求（逐条实现）

### A. 数据通道
* **A1** 预览必须持有 `PlotSession`（`fast_blf_core.open_plot_session`），**绝不**在窗口里反复调 `series_for_plot`。
* **A2** `paintEvent` **不允许**访问内核：可见窗口的数据由 `session.view(t0,t1,width_px)` 取，
  在**窗口变化时**取一次并缓存数组；十字线移动/图例高亮**只重绘**，不重新取数。
* **A3** 缩放/平移**拖拽期间**用粗粒度（`width_px=400`）保流畅，**松手后**用实际宽度再取一次精化。
* **A4** 会话生命周期：预览窗口关闭时 `session.close()`；主窗口保留**最近一次**会话以便"再次预览秒开"
  （缓存本身在磁盘上，命中即 `cache_hit=true`）。打开会话在 Worker 线程里做，**带确定进度**（用 `progress_cb`）。

### B. 三种显示模式（可切换，写进预设）
* **B1** `车道`：每信号一行，共享时间轴，各自左侧 Y 轴标签（**默认模式**）。
* **B2** `多 Y 轴叠加`：同一绘图区，按 `unit` 分轴（沿用现有实现思路），最多 4 条实轴，其余归一化并在图例标注。
* **B3** `单 Y 轴`：全部信号共用一根 Y 轴（量纲不同时**必须**在顶栏红字提示"量纲混杂，仅建议同量纲信号"）。
* **B4** 模式切换 = 纯布局重算，**不得**重新取数（复用已取的数组）。

### C. 每信号样式（颜色 / 线型 / 可见性）
* **C1** 颜色：每行一个色块按钮，点击弹 `QColorDialog`；默认调色板要**高对比**（深色主题可读）。
* **C2** 线型：行右键菜单 → `折线` / `阶梯`（ZOH，适合状态量）/ `散点`。
* **C3** 可见性：行首勾选框（不参与"全选"三态统计的语义要么说清，要么就用可见性做全选——**二选一，选后者**）。

### D. 信号面板：**一个三态复选框**（用户明确要求）
* **D1** 面板顶部只有一个 `QCheckBox`，`setTristate(True)`，文案 `全选（3/96）`：
  * 全部选中 → `Checked`；全不选 → `Unchecked`；部分 → `PartiallyChecked`。
  * 点击 `PartiallyChecked`/`Unchecked` → **全选**；点击 `Checked` → **全不选**。
* **D2** **禁止**出现"全选/全不选/反选"三个按钮（用户明确否掉）。
* **D3** 列表变化 → 复选框状态自动重算（不得递归触发）。
* **D4** 面板里支持按名字过滤（一个输入框），过滤只影响列表显示，不影响三态统计口径（口径 = 全部可见行）。

### E. 顶栏与信息（"知道自己看的是哪一段"）
* **E1** 顶栏必须常驻显示：`时间口径` 下拉、`显示模式` 下拉、`窗口 12.40–22.40 s`、`全量 1820.0 s`、
  `可见 3 条 · 3.2k 点`、`缓存 152/200 MiB`（来自 `session.info()` 与 `view()` 的返回）。
* **E2** 时间口径切换 → `session.set_time_format()` + 重绘（**≤16ms，且不得取数**）。
* **E3** 初始窗口 = **最前 2 秒**（或全量 2%，取小者），**不是全域**；`双击`复位到全域；`滚轮`以光标为中心缩放；`拖动`平移。
* **E4** 初始可见信号 **最多 3 条**（按勾选顺序取前 3），其余默认不画（用户可在面板勾）。

### F. 缓存超额 / 预取 的界面（不许弹窗报错）
* **F1** `CACHE_BUDGET_EXCEEDED`：在预览窗口里显示**内联横幅**（红字）+ 三个动作按钮：
  `提高上限并重试`（跳设置）/ `只预览更少报文`（回到主窗口）/ `不建缓存继续（较慢）`。
* **F2** 未缓存信号被勾选 → 顶栏显示 `正在加载新信号… 3/7`，**不冻结**已有信号的缩放/平移。

## 自检（必须真跑，输出贴交付说明）
1. 既有 6 条自检全 exit=0：`--selftest` / `--selftest-parse` / `--selftest-deep` / `--selftest-config` / `--selftest-progress` / `--dump-check-states`
2. **新增 `--selftest-plot`**（必须实现），打印 `PLOT_OK ...` 且 exit 0，断言：
   * 用 `fixtures/multi_channel.blf`+`demo.dbc` 开会话 → 预览窗口可构造（offscreen）
   * 三种模式各切一次 + 时间口径 4 种各切一次 → 无异常，且**取数次数不增加**（用计数器证明：切模式/口径时 `view()` 调用次数 = 0）
   * 三态复选框：全选 → 96/96 且 `Checked`；全不选 → `Unchecked`；只勾 1 条 → `PartiallyChecked`
   * 可见点数 ≤ `2*width_px` 每信号
   * 离屏渲染一帧（`QImage`）耗时 ≤ 30 ms（打印实测）
3. **性能实测**（打印数字，主会话会复核）：用 8 个 7MB 切片开会话后，
   缩放 50 次 + 平移 50 次的**单帧耗时 p50/p95**；`set_time_format` 20 次耗时 p95。
